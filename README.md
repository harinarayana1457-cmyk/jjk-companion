

# 🌌 Jujutsu Kaisen Companion App

An interactive, single-page dashboard application built to serve as the ultimate database and utility suite for Jujutsu Kaisen sorcerers and enthusiasts. Explore character archives, map cursed energy, and simulate tactical combat scenarios in a clean, high-performance interface.

---

## 🛠️ Tech Stack

* **Frontend Framework:** HTML5, Modern JavaScript (ES6+)
* **Styling & Layout:** Tailwind CSS (via CDN for fluid utility-first layout architectures)
* **Development Accelerator:** Google Antigravity SDK 2.0 (Python-driven multi-agent codebase generation)

---

## ✨ Core Features

* **Jujutsu High Database:** An interactive dashboard hosting an extensive registry of Sorcerers and Cursed Spirits, tracking combat grades, unique innate techniques, and canonical statistics.
* **Cursed Energy Analysis Terminal:** A dedicated UI module built to evaluate individual power thresholds and simulate domain traits.
* **Tactical Turn-Based Battle Simulator:** Select your sorcerer (Gojo, Itadori, Megumi) and engage in strategic combat loops against curses using specialized technique prompts.

## 🚀 Developer’s Insight: The Antigravity Experience

> **Note:** This project marks my absolute first time developing an application using the **Google Antigravity SDK**, and the experience was nothing short of awe-inspiring.

As a technical innovator, I am used to traditional software pipelines, but spinning up a localized, complex, multi-file web app through a terminal-driven autonomous agent runner was a complete paradigm shift. Two things blew me away completely:

1. **Mind-Blowing Context Awareness:** The SDK didn't just write generic boilerplate code; it deeply understood the intricate domain lore of *Jujutsu Kaisen*. It seamlessly structured separate modules (`app.js`, `characters.js`, `styles.css`) with consistent state mapping, managing tool calls and system confirmations effortlessly.
2. **Blazing Execution Speed:** The rate at which the platform evaluated prompts, adjusted script constraints, handled local directory formatting, and prepared deployment states was incredibly fast.

Witnessing theoretical AI agent orchestration translate instantly into a fully functioning, clean Single Page Application in real-time has fundamentally redefined how I view rapid software prototyping.

## 📦 Local Setup Instructions

If you want to pull this repository and run the JJK Companion App locally on your machine, follow these steps:

1. **Clone the Repository:**
```bash
git clone https://github.com/harinarayana1457-cmyk/jjk-companion.git

```


2. **Navigate into the project directory:**
```bash
cd jjk-companion

```


3. **Launch the Application:**
Simply double-click the `index.html` file to open the companion system directly in your default web browser—no heavy web-servers or package installations required!
